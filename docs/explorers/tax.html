Who pays a sugar tax?

Interactive supply-and-demand explorer: tax incidence, revenue, and deadweight loss.

← PUBADM 513

Suppose Boise puts a tax on sugary drinks, collected from sellers. Who ends up paying it: the people buying soda, or the stores selling it? How much money does it raise, and how much buying and selling simply stops happening? Move the sliders and find out. This is the model behind Doing Economics Lab 2, which uses data from Berkeley’s real soda tax.

viewof t = Inputs.range([0, 1], {step: 0.05, value: 0.5, label: "Tax ($ per liter)"})
viewof buyerResp = Inputs.range([1, 5], {step: 0.5, value: 2, label: "How much buyers cut back (1–5)"})
viewof sellerResp = Inputs.range([1, 5], {step: 0.5, value: 2, label: "How much sellers cut back (1–5)"})
Q0 = 100
P0 = 2
b = 0.04 / buyerResp
d = 0.02 / sellerResp
a = P0 + b * Q0
c = P0 - d * Q0
Qt = Math.max(0, Q0 - t / (b + d))
Pb = a - b * Qt
Ps = Pb - t
buyerShare = t > 0 ? (Pb - P0) / t : d / (b + d)
revenue = t * Qt
dwl = 0.5 * t * (Q0 - Qt)
cs = 0.5 * (a - Pb) * Qt
ps = 0.5 * (Ps - c) * Qt
band = (from, to, lo, hi) => d3.range(from, to + 1e-9, Math.max((to - from) / 60, 1e-6)).map(q => ({q, lo: lo(q), hi: hi(q)}))
curve = f => d3.range(0, 201, 2).map(q => ({q, p: f(q)}))

Try this

  1. Set buyers’ response to 1: people keep buying soda almost no matter the price. Who pays most of the tax now? What happens to the deadweight loss?
  2. Now set buyers’ response to 5. The tax shifts toward sellers, sales fall more, and revenue drops. If the goal is public health rather than revenue, which world do you want to be in?
  3. Double the tax from $0.50 to $1.00. Does the deadweight loss double, or do something else? Why?
  4. The statute says sellers pay the tax. Does that decide who actually pays it?
